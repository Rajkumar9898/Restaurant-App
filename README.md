# 🍽️ Restaurant Reservation Web App

A full-stack MERN (MongoDB, Express.js, React.js, Node.js) application that allows users to reserve tables at a restaurant and provides admins with tools to manage reservations and availability.

---

## 🚀 Features

- Browse and book available reservation time slots
- Secure RESTful API endpoints
- Responsive front-end design
- Cloud-hosted MongoDB database (MongoDB Atlas)

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Axios, React Router
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
